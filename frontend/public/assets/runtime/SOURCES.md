# Runtime icon sources

- `codex.svg`: Codex color mark from `@lobehub/icons-static-svg@1.94.0` (`icons/codex-color.svg`), with the white backing plate removed for a transparent background.
- `claude-code.svg`: Claude Code color mark from `@lobehub/icons-static-svg@1.94.0` (`icons/claudecode-color.svg`).
- `modu-code.png`: deterministically cropped and background-extracted from the official `openmodu/modu` repository `logo.png`; the silhouette is unchanged.
- `grok.svg`: Grok mark from `@lobehub/icons-static-svg@1.94.0` (`icons/grok.svg`), unmodified.
- `deepseek.svg`: DeepSeek color mark from `@lobehub/icons-static-svg@1.94.0` (`icons/deepseek-color.svg`), unmodified. It stands for the DeepSeek Harness runtime.
- `pi.svg`: an original Greek letter pi drawn for this project. Lobe Icons ships a `pi.svg`, but that is Inflection AI's Pi assistant, a different product from the Pi coding agent this runtime drives; using it would attribute the wrong mark. A plain typographic glyph claims no brand.
